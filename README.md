## Privacy & Cryptography

- **[Ome](https://ome.network)** — Private k-of-n multisig on Aztec. k members to spend, t to read, and no one holds the viewing key.
- **[zkPersona](https://github.com/zkpersona)** — Noir libraries: [JWT](https://github.com/zkpersona/noir-jwt), [HMAC](https://github.com/zkpersona/noir-hmac), [Ethereum event proofs](https://github.com/zkpersona/noir-ethereum), [social verification](https://github.com/zkpersona/noir-social-verify), [ring signatures](https://github.com/zkpersona/noir-ring-signatures).
- **[zk-dnssec](https://github.com/envoy1084/zk-dnssec)** — Zero-knowledge DNSSEC validation.
- **[fhe-dksap](https://github.com/envoy1084/fhe-dksap)** — FHE-based stealth addresses in Rust.
- **[bls-solidity](https://github.com/envoy1084/bls-solidity)** — BLS12-381 in Solidity via the EIP-2537 precompiles.
